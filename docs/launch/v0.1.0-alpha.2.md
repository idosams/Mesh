# Mesh v0.1.0-alpha.2

**Released September 16, 2026.** The GitHub prerelease was published only after the exact public
commit had green CI and the matching archive passed its packaged-window and checksum verification.

This hotfix alpha keeps the local macOS workspace boundary from alpha.1 and addresses the first
hands-on tester feedback:

- Review no longer crashes when a saved change includes `.DS_Store` or another unsupported binary
  format. It shows exact saved metadata without inventing a preview.
- Files now presents an accessible nested folder tree instead of making a flat dropdown the main
  view.
- Current shows read-only live changes while an assigned agent is working and provides direct
  cards for switching among recent and agent-assigned workspaces.

Mesh is a local macOS workspace for working with coding agents
without sharing one mutable folder. It imports an ordinary project into an application-managed
copy, gives agents independent native folders, retains private saved points, and makes review and
export explicit.

## Try these journeys

- Import a disposable project and confirm that its original folder stays untouched.
- Open the managed folder in an editor, change a text file, return to Mesh, and save it privately.
- Start and finish a Codex handoff, then record the resulting reviewed version.
- Compare text, image, PDF, or Office changes in Review.
- Open an earlier saved point as an independent folder without rewinding the current workspace.
- Export selected private content to a separate empty destination folder after reviewing its plan.

## Distribution boundary

- Apple-silicon Mac, macOS 11 or newer.
- The archive is ad-hoc signed and unnotarized. A downloaded copy requires an explicit macOS
  **Open** confirmation. Never disable Gatekeeper globally or strip quarantine metadata.
- Approval and **Update original folder** are unavailable because they require a separately
  Developer-ID-signed build with a stable Apple application identity.
- The GitHub release includes a friend-installable DMG. It remains ad-hoc signed and unnotarized.
- There is no automatic updater. Quit every Mesh process before replacing the application.
- Windows and supported Linux packages are not included.

## Safety boundary

- Starting or finishing an agent never advances the shared version.
- A source folder is not modified during import.
- Unsupported, ambiguous, or changing filesystem entries stop the relevant operation instead of
  being guessed.
- The alpha is local-only. It has no hosted relay, web review, or supported multi-device session.
- Keep an independent backup and avoid irreplaceable work while evaluating an alpha.
