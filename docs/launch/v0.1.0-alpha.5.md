# Mesh v0.1.0-alpha.5

Family-and-friends technical alpha for Apple-silicon Macs. This release brings the local-readiness
fixes together with an explicit English/Hebrew interface choice. It remains a testing release,
not a signed, notarized production installer.

## Changes

- Empty or Git-metadata-only source folders are refused clearly at preview/preparation, before
  journal creation. The source remains untouched. Import a folder with at least one included
  file or subfolder. Empty project creation is not supported by this release.
- Historical-copy handling is repaired for deleted entries; an entirely empty saved version
  cannot currently be copied into a new workspace and receives an explicit refusal.
- Ordinary recovery avoids redundant ancestry scans while preserving cycle and integrity checks.
  The measured 4,006-record workload improved from 6.9 seconds to about 0.24 seconds on the test Mac;
  that is a local measurement, not a promise for every device or workload.
- Packaged verification waits through startup verification and distinguishes a refused export
  from a completed one. Actual exported bytes and executable permissions remain mandatory checks.
- The desktop offers English and Hebrew with right-to-left presentation. Project files, paths,
  code, and detailed native diagnostic text retain their original contents.
- User playbooks, public documentation links, macOS document fixtures, and CI coverage are updated.

## First session

Use the delivery ZIP and read `START-HERE.txt`, then `FIRST-SESSION.txt`. Start with a small,
backed-up folder containing a text file. Import it, edit the managed copy, save privately, restart,
and export to a separate empty destination. Verify the exported files before removing any copy.
Choose Hebrew from the language control if preferred. See the [language guide](../localization.md)
for coverage and remaining English fallbacks.

## Limits

This app is ad-hoc signed and unnotarized. macOS requires explicit first-open approval. Never
disable Gatekeeper or strip quarantine. Mesh's protected approval and **Update original folder**
remain unavailable without a validated Apple application identity. There is no automatic updater,
remote team synchronization, Windows package, or supported Linux desktop distribution.

Do not delete existing application-support data during an upgrade. Quit the old app first; keep
it and your projects until the new app has reopened and exported the needed work successfully.

See the [user playbooks](../user-playbooks.md), [public-alpha guide](public-alpha.md), and
[changelog](../CHANGELOG.md). Local evidence from the earlier readiness candidate is recorded
separately in the [validation record](../local-alpha-validation.md); it does not stand in for the
new release's own CI and exact-archive checks.
