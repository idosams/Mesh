# Mesh v0.1.0-alpha.4

**Released September 19, 2026.** This prerelease packages the exact public source commit only after
its source checks, packaged-window proof, and archive checksum verification complete successfully.

This candidate fixes the preview and workspace-identity problems found while dogfooding alpha.3.

## What changed

- Text, Markdown, and JSON files in managed and agent-assigned workspaces now show their actual
  contents in the inline preview instead of an incorrect inspection-unavailable message.
- Stable workspace projections preserve the selected file across refreshes and reduce visible
  flicker while agent work is changing.
- Version folders opened in Finder, terminals, editors, or software pickers now identify themselves
  as `Mesh Version - Working Folder`; the previous internal `mounts` name remains readable for
  existing alpha workspaces.
- Approval setup in this ad-hoc build now stops immediately with the real Apple-identity requirement
  instead of beginning a flow that cannot complete.
- Packaged export verification waits for the filesystem receipt, preventing a successful journey
  from being reported before exported content is visible.

## Distribution boundary

- Apple-silicon Mac, macOS 11 or newer.
- The revision-named delivery ZIP contains the exact app archive, canonical JSON manifest,
  SHA-256 file, and tester guides. The app is ad-hoc signed and unnotarized, so macOS requires an
  explicit Finder **Open** confirmation. Never disable Gatekeeper globally or remove quarantine
  metadata.
- Human approval and **Update original folder** remain unavailable. Making approval operational
  requires a Developer-ID-signed Mesh application with a validated stable Apple identity; this
  release fixes the failed setup experience but does not claim that identity.
- There is no automatic updater. Quit every Mesh process before replacing the application.
- Windows and supported Linux packages are not included.

## Safety boundary

- Starting or finishing an agent never advances the shared version.
- A source folder is not modified during import.
- Open and Reveal are closed native actions bound to exact workspace or saved-review identity; the
  renderer cannot submit an arbitrary filesystem path.
- Unsupported, ambiguous, stale, or concurrently changing entries fail closed with a specific
  recovery message instead of being guessed.
- Keep an independent backup and avoid irreplaceable work while evaluating an alpha.
