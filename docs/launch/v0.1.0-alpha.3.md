# Mesh v0.1.0-alpha.3

**Released September 18, 2026.** This prerelease packages the exact public source commit only after
its source checks, packaged-window proof, and archive checksum verification complete successfully.

This candidate makes Mesh feel more like a focused IDE and code-review workspace while keeping its
local custody and exact-review boundaries intact.

## What changed

- Files is now a content-first explorer with a recognizable file tree, search, keyboard navigation,
  breadcrumbs, persistent selection, and collapsible explorer and details panes.
- Selecting a supported text file shows its actual content in Mesh. Files and folders retain direct,
  user-triggered actions to open with the default app or reveal in Finder.
- Changes uses a searchable source-control navigator and shows actual inline or split text changes,
  with stable selection and navigation even in large workspaces.
- Saved Review groups changed files and provides appropriate read-only viewers for text, raster
  images, PDF, Office, and metadata-only files. Exact saved sides can be opened or revealed without
  mutating the workspace or original project.
- **Live agent work** can be inspected before Finish through bounded, read-only snapshots. It stays
  visibly mutable and cannot save, record, approve, export, or update the original folder.
- Workspace-open failures now explain whether a managed workspace is missing or an ordinary folder
  should be imported, and offer clear retry or forget actions while keeping the safe workspace open.

## Distribution boundary

- Apple-silicon Mac, macOS 11 or newer.
- The revision-named delivery ZIP contains the exact app archive, canonical JSON manifest,
  SHA-256 file, and tester guides. The app is ad-hoc signed and unnotarized, so macOS requires an
  explicit Finder **Open** confirmation. Never disable Gatekeeper globally or remove quarantine
  metadata.
- Approval and **Update original folder** remain unavailable because they require a separately
  Developer-ID-signed build with a stable Apple application identity.
- There is no automatic updater. Quit every Mesh process before replacing the application.
- Windows and supported Linux packages are not included.

## Safety boundary

- Starting or finishing an agent never advances the shared version.
- A source folder is not modified during import.
- Open and Reveal are closed native actions bound to exact workspace or saved-review identity; the
  renderer cannot submit an arbitrary filesystem path.
- Unsupported, ambiguous, stale, or concurrently changing entries fail closed with a specific
  recovery message instead of being guessed.
- Keep an independent backup and avoid irreplaceable work while evaluating an alpha.
